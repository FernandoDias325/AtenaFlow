Simulador de Chat - Hi Platform

Este campo simula exatamente o comportamento (CSS flexbox) que causou o bug na Hi Platform.

Como testar a correção:

  1. Se certifique de que instalou a nova versão compilada (via `npm run dev` ou usando o novo .zip).
  2. Clique no campo de texto abaixo.
  3. Abra a AtenaFlow e injete um script que contenha múltiplas quebras de linha.
  4. Se as linhas aparecerem umas abaixo das outras (vertical), a correção funcionou perfeitamente!
  5. Dica: Se a correção não estivesse aplicada, o texto ia se espalhar horizontalmente como na sua foto.
